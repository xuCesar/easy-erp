# Phase 1.8 UI/UE Acceptance Checklist

日期：2026-05-20

## Admin

- 登录页显示 Phase 1.8 工作台定位，登录失败有可见反馈。
- 登录成功后默认进入 `/workbench`。
- 未登录状态不展示业务路由内容。
- 左侧导航可以进入工作台、考勤结果、审批、月报、组织、员工、班次、考勤组。
- 顶部范围条展示并可编辑工厂 ID、组织 ID 和月份。
- 切换路由后，范围条中的工厂 ID、组织 ID 和月份不丢失。
- 点击刷新后，工作台 KPI、考勤结果、待审批和月报数据刷新。
- 工作台第一屏能看到员工总数、考勤结果、异常记录、待审批、未锁定月报。
- 考勤结果页默认展示异常优先视图，并可切换全部、正常、迟到、早退、缺勤、缺卡。
- 审批页可切换请假/补卡，可按状态加载列表。
- 审批页选择单据后，详情区展示员工、类型、状态、时间和原因。
- 有审批权限时，可在详情区直接通过或驳回待处理单据。
- 无权限时，审批按钮禁用，页面仍可读。
- 月报页展示月报员工数、已锁定数、未锁定数。
- 月报页可创建导出任务，并可按任务 ID 查询状态。
- 基础资料页不再裸露为单一表格，页面头部和摘要信息清晰。

## Miniapp

- 打卡页第一屏展示考勤组、日期、班次、上班/下班状态和下一步动作。
- 上班打卡、下班打卡、今日无需打卡三态文案可区分。
- 打卡提交中主按钮禁用并显示提交中反馈。
- 打卡上下文加载失败时可重新加载。
- 打卡结果页明确展示有效或异常结论。
- 异常打卡结果页提供补卡入口。
- 考勤记录页异常记录优先展示。
- 请假页展示提交前确认、提交中状态和提交后反馈。
- 补卡页展示提交前确认、提交中状态和提交后反馈。
